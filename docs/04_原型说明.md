# 心屿 MindIsle · 原型说明

> 参赛赛题：赛题一（AI 辅助开发·创意产品原型）
> 本文件是提交包里的第 4 份材料：说明怎么把原型跑起来、它做了什么、它明确不做什么。

## 1. 它是什么

一个**不会害人的情绪陪伴对话工具**。三个角色（倾听者 / 引导者 / 危机支持）由规则状态机切换，所有回复在发出前过一道**安全审查层**；危机句走固定模板与资源卡，不经过模型。

- 不诊断、不承诺保密、不替代真人；
- 不声称疗效，只说明"完成交互功能验证"；
- 演示用例全部虚构，不含任何真人倾诉。

## 2. 运行方式（本机）

```bash
# 1) 环境：Python 3.11（本机用 py -3.11 建环境，不要用 3.14）
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2) 密钥：复制 .env.example 为 .env，填 LLM_API_KEY
#    没有 key 也能跑：设置 MOCK_LLM=1 走离线剧本
set MOCK_LLM=1

# 3) 启动
streamlit run app.py
```

线上演示：<https://xinyu-mindisle.streamlit.app>（分支 `main`，主文件 `app.py`，密钥在 Secrets）。

## 3. 三十秒验证（三条命令）

```bash
.venv\Scripts\python.exe -m pytest -q      # 期望 132 passed
.venv\Scripts\python.exe contract_check.py  # 期望 11/11 + 5/5 + 20/20
.venv\Scripts\python.exe metrics.py         # 期望 10/10、0/20、12/12、10/10
```

前两条是提交前门禁；第三条只跑规则层与状态机，不调模型，可离线复现。

## 4. 目录

| 路径 | 作用 |
|---|---|
| `app.py` | Streamlit 页面与固定七步管线；L3 短路在这里发生 |
| `agent.py` | `call_llm` / 人设 prompt 拼装 / MOCK 剧本 / 摘要与复核用 prompt |
| `roles.py` | 5 套人设卡 + `RULES` 20 条规则（唯一来源） |
| `coordinator.py` | 三角色状态机 + 5 轮窗口聚合 + 风险地板（只升不降） |
| `guardian.py` | 规则扫描 → 豁免 → 分级 → 复核 → 重写 / 复检 / 兜底 |
| `memory.py` | 8 字段白名单读写、摘要节流、脱敏、真删、迷你 lorebook |
| `panel.py` | 记忆面板（只读 8 字段 + 两项可改 + 导出 + 二次确认清空） |
| `resources.py` | 情绪 → 资源卡（纯函数） |
| `theme.py` | 三套配色（樱花 / 抹茶 / 落日） |
| `logger.py` | 9 字段结构化日志，不写用户原文 |
| `metrics.py` | 四个指标脚本（只读测试集） |
| `contract_check.py` | 11 个签名 + 5 个常量 + 20 条规则校验 |
| `tests/` | 132 条测试（考核口径 48） |
| `docs/` | 项目文档、方案 PPT、演示视频、证据 |

## 6. 明确没做

- 没有真人用户测试、没有问卷样本（报告第 7 章写明）；
- 没有情绪打卡与趋势图、没有语音、没有多轮长期档案（云端磁盘是临时的）；
- 没有接入真实转介闭环：资源卡给号码，但不代办预约；
- 不引入 LangChain / 向量库 / FastAPI / 前端框架 / 数据库 —— 4 周 6 人的取舍，理由写在 PPT 第 11 页。
