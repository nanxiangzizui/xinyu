# 心屿 MindIsle · S6 匿名问卷（10 题）与统计口径

> 用途：回答「这些时刻是不是真的存在」。只问**场景与频率**，不问疗效、不做量表、不留身份信息。
> 目标：30 份（6 个人各发 5 份即可）。填完约 3 分钟。
> 这份文件是**发放用的**，不是结果。结果另存 `docs/evidence/P40-survey-<日期>.md`。

---

## 0 发放说明（给发问卷的人，不打印给填的人）

1. **匿名怎么做到**：纸质问卷不写名字、不填学号手机号，填完折起来投进一个盒子；线上问卷关闭「记录微信昵称 / IP / 地理位置」，不要用需要登录的收集工具。
2. **自愿**：任何一题都可以跳过，中途可以停，不用解释。
3. **只统计频率**：最后写的是「30 人里有 N 人……」，不是「证明心屿有效」。
4. **原始问卷 7 天后销毁**，只保留汇总数字与最多 3 条匿名原话（原话里出现的人名、学校、单位一律删掉）。
5. **不要在课堂上当众收**，也不要在收的时候问「你为什么选这个」。

## 2 统计口径（回收后怎么数）

| 题号 | 题型 | 分母 | 输出格式 | 备注 |
|---|---|---|---|---|
| 1 | 单选 | 有效份数 N | 「大一 6 / 大二 11 / …」 | 不写比例，样本太小 |
| 2 | 单选 | N | 「30 人里 18 人至少有过 1 次」 | 核心题，必须报 |
| 3 | 多选 | N | 每项「N 人（可多选）」 | 各项之和可大于 N |
| 4 | 多选 | N | 每项 N 人 | 「没有这种情况」单独列出 |
| 5 | 多选（限两项） | N | 每项 N 人，并报「选了至少一项」的人数 | 若有人选超过两项，只记前两项 |
| 6 | 单选 | N | 会 / 有点 / 不会 / 没想过 各 N 人 | 与第 4 题「怕被说想太多」对照 |
| 7 | 单选 | N | 四个时段各 N 人 | 用来定「什么时候推 12356」 |
| 8 | 单选 | N | 四项各 N 人 | 对应「我的数据」页的说法 |
| 9 | 单选 | N | 四项各 N 人 | **不要**据此说「资源没用」 |
| 10 | 开放 | — | 最多引用 3 条 | 去人名 / 去校名 / 去单位 |

**两条交叉**（只报人数，不做显著性）：

- 第 2 题「至少 1 次」× 第 4 题「没去求助」→ 「有过难受、且有过没去求助」的人数。
- 第 5 题「告诉我下一步该找谁」× 第 9 题「会 / 可能会」→ 说明「给路径」和「真会去」之间的差距。

**原话怎么挑**：挑 3 条，一条说「难受」、一条说「不敢去」、一条说「想要什么」。挑完把主语模糊掉（「我们班有人」→「有人」），不挑最惨的那条。

**报告里能写 / 不能写**

- 能写：「30 份回收中，18 人表示过去一个月至少有过一次『晚上很难受但不知道跟谁说』。」
- 能写：「14 人勾了『怕被记录』或『怕被说想太多』。」
- 不能写：「问卷证明心屿有效」。
- 不能写：「多数学生有抑郁倾向」——问卷没问，也不能问。
- 不能写：「N% 的学生需要心理干预」。
