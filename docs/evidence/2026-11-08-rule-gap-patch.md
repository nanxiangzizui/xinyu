## 2 改了什么（逐条正则）

说明：X 组豁免的判定是"小句内命中，且硬词（HARD_WORDS）全部落在 X 命中 span 内"，所以改写正则就等于改写"这句话算不算引用/否定"。

- `X01`（roles.py:118）原 `(不|没)想死|不会自杀|没想过自杀`
  → `((不|没)想死|不会自杀|(没有|没|从没|从来没|从未|并未)想过?(要)?(死|自杀))`
  补"没有想过""从没想过要"。**"我想过自杀"仍然 L3**（没有否定词，任何分支都不吃）。
- `X03`（roles.py:126）原只认"语境词在前"（电影…自杀）
  → 增加**反向分支** `(自杀|死了|想死).{0,6}(论文|作业|课程|报道|新闻|研究|案例|课件|考题|题目|作文)`，正向语境词也补了论文 / 作业 / 课程 / 报道 / 新闻 / 研究 / 案例 / 课件 / 考题 / 题目 / 作文。
  反向分支卡 6 字，防止"我想死"和很远处一个"论文"凑成引用。
- `H04`（roles.py:152）原 `(跳楼|跳桥|上吊|从楼上)`
  → 补 `跳河|跳湖`、`(天台|楼顶|栏杆|窗台).{0,6}(跳|往下)`、`(想|要|准备|打算|干脆).{0,4}跳(下去|下来)(?!.{0,6}(游泳|洗澡|玩水))`。
  负向断言是这次唯一"防过头"的补丁：没有它，`我想跳下去游泳` 会被打成 L3。
- `H06`（roles.py:160）原只认 `(一把|整瓶|一瓶|几瓶|很多).{0,4}药`
  → 补 `全`、`安眠药.{0,8}(吃|吞|喝|全)`、`(买|囤|攒|存).{0,8}安眠药`。
  **不**把 `安眠药` 单独当命中，否则 `医生给我开了安眠药` 会变成危机。

## 4 补丁后的横切复查（`_probe_rules2.py` 跑 28 句）

保留正确行为：
- `我不想死` → L1 X01；`我从来没想过自杀` / `我从没想过要自杀` → L1 X01
- `我想过自杀` / `我想过要自杀` / `我最近总想自杀` → L3 H02（否定豁免没被放宽成"只要含想过"）
- `我不想死，但我想自杀` → L3（小句混合取最高）
- `老师让我们写一篇关于自杀的论文，我最近真的想死` → L3（引用只豁免自己那一小句）
- `我站在楼顶吹风` → L1；`我在天台`（无动作）→ L1
- `医生给我开了安眠药` → L1；`我买了药治感冒` → L1
- `我买了瓶安眠药，想一把吃掉` / `我买了很多安眠药` / `我把安眠药全吃了` → L3 H06
- `我室友说他不想活了` → L2 X05；`累死了，不想活了` → L3 [X04,H01]

## 5 已知保留的取舍（不藏）

1. `我跳河救人` → **L3**。`跳河` 单独命中 H04。按"L3 宁可误报"接受；若以后误报投诉变多，再考虑加"救人"负向断言。
2. `我想自杀的想法写在论文里` → **L1**。引用豁免优先于 H02。属于 X03 的既定语义（和"书里"同处理）。
3. X01 放宽后，`我从没想过要自杀` 这类"否认 + 要"也进豁免；**"想过"本身不吃豁免**，靠的是前面必须有否定词，这一条在用例表里单独盯着（`我想过自杀` → L3）。
