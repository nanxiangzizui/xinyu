## 5 五处口径修正

1. **350 行红线 → 抽 `panel.py`**。S17 结束时 `app.py` 333 行，面板按步骤写法会破 350。把 UI 与标签映射抽成第 10 个业务模块；11 个契约签名不变，`contract_check` 仍 11/11。`panel` 只依赖 `memory`，清空动作 `on_clear` 由 `app` 注入 `_clear`，避免 `panel ↔ app` 循环导入。
2. **`st.write(memory.get(k))` 会把列表显示成一坨**。改为逐字段转人话：列表用顿号拼接、空值显示“—”，并走中文标签；否则 `emotion_tags` 会显示 `['学业']`。
3. **步骤示例的语气值是中文，但落盘必须是枚举码**。`memory` / `agent` 依赖 `neutral / gentle / light / direct`（`roles.py` 与 prompt 同源）；面板用 `format_func` 显示中文、落盘枚举码，避免“温柔”写进 `preferred_tone` 后 prompt 失配。
4. **导出含 `last_updated`，面板不展示**。`last_updated` 是记忆文件字段、对用户无意义（步骤 §5.1），但它能帮用户确认“这条记忆是什么时候的”，所以导出保留；导出前同样 `scrub`。
5. **清除后的 `session_state` 由既有 `_clear` 负责**。它清 `messages / turn / cooldown / ever_crisis / last_role / last_level / last_reason / levels`、换新 `query_params["u"]` 后 `st.rerun()`；面板的 checkbox / button key 带 sid，换会话后确认框自动回到未勾选。
