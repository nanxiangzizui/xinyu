## 2 部署前修掉的一个必炸问题

Streamlit Cloud 的密钥放在 `st.secrets`，不是环境变量；`agent.py` / `memory.py` 只读 `os.getenv`，线上也没有 `.env`。不处理的话，首屏就是「未配置 LLM_API_KEY」。

修法：`app.py:24-45` 新增 `_bridge_secrets()`，在 `import memory/agent`（`app.py:42-45`）**之前**把 `st.secrets` 铺进 `os.environ`。顺序不能反：`memory.py` 的 `DATA_DIR = Path(os.getenv("DATA_DIR", "data/memory"))` 是模块级常量。

实测：把 `.env` 改名、只留 `.streamlit/secrets.toml`（`MOCK_LLM="1"`）时，AppTest 一轮对话正常回复、0 错误 0 异常。
