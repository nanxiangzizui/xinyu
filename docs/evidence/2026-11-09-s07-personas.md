## 4 真实模型抽样（`MOCK_LLM=0`，同一句「我最近好累」）

| 人设 | 回复 |
|---|---|
| 知心姐姐 | 听着就觉得你撑了很久。今天这累，是身上累，还是心里累？ |
| 温柔学长 | 嗯，听你这么说，感觉你扛了不少。是那种睡一觉也缓不过来的累吗？ |
| 理性导师 | 累主要来自哪方面？说具体些，我们分开看。 |
| 元气同伴 | 累成这样还来找我聊，你挺不容易的。今天有没有哪一刻稍微松快一点？ |
| 沉稳树洞 | 嗯。累了就歇着，我在。 |

## 5 踩到的坑：示例被逐字复读

第一版提示词写「示例（照这个语气，不要照抄内容）」，温度 0.7 下模型**直接复读示例原句**——五个输入三次调用几乎原样返回。

改法：换成「示例只示范语气与句长，不要复用其中任何句子；每次用你自己的话说。」，温度 0.8 重测，五卡都能改写（见 §4）。

教训：**否定式短指令（“不要照抄”）对短 prompt 几乎无效**，要讲清“示例的作用是什么、复用它算错”。
