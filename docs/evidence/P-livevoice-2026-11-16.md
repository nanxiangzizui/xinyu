## 7 边界与未做

- n=8 组、单人判读、无盲读；temperature=0 不消除模型版本漂移，换 model 版本要重跑。
- 只覆盖 L1 与灰区；L3 不调 LLM（`guardian_pre_check` 短路），所以活人感层对 L3 零影响——这是设计，不是遗漏。
- 「分多条消息」的流式递进没做：Streamlit + 当前渲染结构下会把一条回复拆成多个气泡，属于 UI 改动，不在本轮。
- 8 条禁用只做了「不进 prompt + 测试防回流」，没有做「模型偶尔自发撒娇」的输出侧拦截（那属于 `guardian_post_check` 扩词表，需单独评审）。
