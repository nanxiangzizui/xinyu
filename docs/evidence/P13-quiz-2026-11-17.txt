九、m00425 讨论轮修正（2026-11-17 追加）
----------------------------------------
问题：报告后面用户说「帮我分析分析这个结果」，AI 只回一句反问
（「这份野心，是让你有劲，还是让你累？」），把球又踢回去。

改法（都是 prompt 层，不动报告与计分）：
1. quiz_data：四个游戏各加 dim_notes（22 条中文维度解释，如
   野心=知道自己要什么、思辨=把事想清楚再说），只给讨论时当抓手。
2. quiz_store：CUES 补「这个结果 / 这份结果 / 那份结果」（只收「结果」
   两字会把「结果我还是没去」勾出来，等于 AI 主动想起）；
   ANALYZE_CUES = 分析 / 聊聊 / 说说 / 探讨 / 怎么看 / 什么意思 / 准吗 /
   解读 / 讨论；命中时 _block 追加 ANALYZE_LINE：
   「先说最高的一项是什么样，再说最低的一项，最后把两项放一起说一句；
     3–5 句、200 字以内……先给内容再提问，不要整条只有一句反问，
     不要下结论说对方就是某种人，也不要建议对方改变。」
   _note_line 只解释最近一次、只解释有分的项；BLOCK_MAX 420→640。
3. style 第 13 条追加：「对方想聊结果时，『每轮只做一件事』让位：
   先从最高的一项说起，讲具体一点，可以多说两句，别只回一句反问。」
