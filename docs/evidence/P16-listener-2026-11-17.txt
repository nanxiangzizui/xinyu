触发：用户 m00002 贴 A 模式趣味测试对话截图，指出「左侧当前角色写的是‘倾听者’，这么多反问不符合人设」，要求「倾听者下非必要不反问」。

一、截图里的问题
连续 4 条助手消息分别以问句收尾：
1. 「想与我探讨一下测试结果吗？」（这是 quiz 报告由代码拼的 CTA，不是模型生成）
2. 「这结果你觉得像你吗？」
3. 「真遇事，你会开口吗？」
4. 「说到这儿，你心里在想什么？」
其中 2–4 是模型生成。原 prompt 里 `SPEECH_RULES` 第 9 条「每轮只做一件事：接住情绪，或问一个具体问题，或给一句话」、第 10 条「想主动开口时问具体的事……」和 `warm_senpai` 的 tone hint 都在鼓励问句；A 模式没有按角色收窄。

二、改了什么
1. `style.py`
   - 新增 `LISTENER_HEAD` / `LISTENER_RULES` / `LISTENER_EXAMPLE` / `LISTENER_REPEAT`。
   - `listener_block(repeat_hint="")`：返回「[这一轮：倾听者]」+ 三条规则 + 一条示例；有 repeat_hint 时追加「上一轮你已经用问句收尾；这一轮用陈述句，把话接住就停。」
   - `listener_hint(history)`：只看最后一条 assistant，`rstrip().endswith(("？","?"))` 才返回 repeat 提示。
   - `trim_listener_question(reply)`：prompt 之外的代码兜底。末尾是问句、且前面还有陈述时，删掉末尾问句；整条只有一句问句时保留。L1 的 listener 才启用，L2 保留「你现在安全吗」这类必要确认。
   - `polish(..., role="")`：L1 且 `role == "listener"` 时调用 `trim_listener_question()`；L3 仍原样返回。
   - `TONE_HINTS["warm_senpai"]` 去掉「再问一个具体的问题」，改成「先说一句你注意到的细节」。
2. `agent.py`
   - `_style_block(..., role="", listener_hint="")`：tone hint 之后，仅 `role == "listener"` 时追加 `style.listener_block()`。
   - `build_system_prompt` 从 memory 读 `_role` / `_listener_hint`，签名仍是 3 参，11 条契约未动。
3. `orchestrator.py`
   - coordinator / cooldown 之后、prompt 之前，A 模式写 `facts["_role"] = dec["role"]` 与 `facts["_listener_hint"] = style.listener_hint(history)`；B 模式不写。
   - `style.polish(reply, persona_id, eff_level, dec["role"])`：把当轮角色传给口吻层，listener 的收尾问句兜底才生效；guide / crisis 不受影响。
4. `quiz_store.py`
   - `ANALYZE_LINE` 从「先给内容再提问」软化为「先给内容；最后想邀请对方说时再问一句，不必为了收尾硬加问句；不要整条只有一句反问」。
5. 测试
   - `tests/test_speech.py` +3：listener 段只在 listener 出现、repeat 只在问号收尾后出现、listener prompt ≤1600。
   - `tests/test_orchestrator.py` +5：A 模式 listener 有段、guide 无段、上一条问号触发 repeat；再加 listener 回复的收尾问句被削、guide 回复的问句保留。
   - `tests/test_style.py` +5：listener 有陈述垫底时削问句、整条只有一句问句时保留、guide 不动、连续多个收尾问句只留陈述、L2 listener 保留安全确认。
   - `tests/test_quiz.py` 补「先给内容 / 不必为了收尾硬加问句」断言。
