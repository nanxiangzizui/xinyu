# P17 首屏放松入口 · 证据（2026-11-18）

## 一、任务与范围

用户要求把入口从「一进去就是对话框」改成列表：

- 最上「与心屿聊聊天」→ 陪伴模式；
- 第二「给心屿一张角色卡」→ 角色卡模式；
- 下面提供放松心情的本地工具，趣味测试也在列表里；
- 用户追加：脑筋急转弯 / 猜谜语 / 成语接龙，三个都加、成语接龙按读音、独立卡片；
- 用户拍板：12 项一起做；环境音上网搜集音频后调用；写下来的内容只放会话（原文「只放绘画」，按同音理解为「只放会话」）；趣味测试独立页 +「聊一聊」；默认首页 + `HOME_HUB=0` 回退。

## 二、交付内容

### 1. 路由与首页

- `app.py` 改为薄路由：`home / companion / rolecard / quiz / relax`。
- 默认 `mode="home"`；`HOME_HUB=0` 回退到原聊天首屏。
- 首页 12 项、四组：
  1. 与心屿聊聊天
  2. 给心屿一张角色卡（`ROLECARD=0` 时隐藏）
  3. 跟着呼吸
  4. 5-4-3-2-1 接地
  5. 一分钟微休息
  6. 写下来
  7. 环境音
  8. 看看别处
  9. 趣味小测试
  10. 脑筋急转弯
  11. 猜谜语
  12. 成语接龙
- 「随便来一个」只在 9 个本地放松页中随机，不随机到聊天 / 角色卡 / 测试。
- 首页底部常驻免责声明与 L3 资源（12356 / 110/120 / 校心理中心 0571-87713518），不折叠。
- 首页不渲染 `chat_input`；进入聊天后才出现输入框。

### 3. 六个放松工具

- **跟着呼吸**：4 秒吸 / 6 秒呼，默认暂停，点「开始」才动；可暂停；`prefers-reduced-motion` 关闭动画。
- **5-4-3-2-1 接地**：五步，可上一步 / 下一步 / 重来，不判级、不记录。
- **一分钟微休息**：随机小动作 + 30 秒计时，默认不自动开始。
- **写下来**：两个文本框（担心清单 / 今天能控制的一件小事）+「撕掉」；只存 `st.session_state`，不写盘、不进 `memory.json`、不进日志、不进 prompt；关闭页面即清。
- **环境音**：雨 / 风 / 海浪三个远程 `<audio loop preload="none">`；点击才 `play()`，1.5 秒淡入，音量滑杆，5/10/15 分钟定时，加载失败提示；无 `autoplay`；页面标注来源与许可。
- **看看别处**：WindowSwap / 古诗文网 / PixelThoughts / Weave Silk / AutoDraw；`st.link_button` 新窗口，标注「将离开本站」；只允许 https + 主机白名单，不嵌 iframe。

### 4. 趣味测试独立页

- `quiz_ui.render_page(sid)`：首页进入后先选游戏，答完显示结果。
- 结果页有「聊一聊这个结果」：带入 `pending_turn="帮我分析分析这个结果"` 回到陪伴模式，由现有讨论轮处理。
- 保留侧栏 `quiz_ui.entry()`，减少对既有测试与使用习惯的破坏。
- 报告仍走原 `quiz.report` + `guardian_post_check`；结果只进 `data/memory/quiz/<sid>.json`。

### 5. 三个文字游戏

- 脑筋急转弯 30 条：看答案 / 换一题。
- 谜语 30 条：提示 / 答案 / 换一个。
- 成语接龙 120 条：每条 `(成语, 首字拼音, 尾字拼音)`；拼音无声调、ASCII 小写、`ü` 写 `v`；同字或同音（声母+韵母相同，声调不计）都算；只接受词库内成语；输入 4 字，`max_chars=8`，`st.form(clear_on_submit=True)`；「帮我接一个」代码补，「换一个开头」重置；无倒计时 / 分数 / 排行榜。
- 全部本地词库，不调 LLM、不联网、不写盘；输入只进 `st.session_state`。

## 四、安全与数据

- 放松页不调用 `agent` / `orchestrator` / `guardian`，不判级，不生成心理建议。
- 写下来只 session：不落盘、不进 `memory.json`、不进日志、不进 prompt。
- 文字游戏不设分数、排名、倒计时、对错评价；不写盘。
- 首页常驻 L3 资源；L3 路径仍由原 `guardian` + `resources` 提供。
- 环境音为公开音频，页面标注来源/许可；服务端不下载、不代理。
- 未新增依赖：仍只有 streamlit / openai / python-dotenv / pytest。
