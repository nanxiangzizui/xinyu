# P23 风格层：两条正向规则 + 轮次议程 + 示例定形（2026-11-20）

> 起因（m00002）：用户问「本项目用蒸馏训练能不能解决 ①AI 味重 ②角色卡活人感弱 ③陪伴达不到调节预期」。
> 结论是**不动权重、先动规格**：同一套 DeepSeek 权重下，风格层改三处就能测出差异。本文件是那次改动的证据。
> 基线 commit `bf92dc9`（v3.1）；改动只在 `style.py` / `agent.py` / `orchestrator.py`（1 行）+ 测试 + 本探针。

## 三、议程位置与措辞的四轮实验（真实 key）

同一段固定历史（用户连续三轮说累、什么都不想干、试过没用），第 4 轮测「会不会给动作」：

| 版本 | 做法 | 结果 |
|---|---|---|
| 放风格区内 | 议程跟在 `LISTENER_RULES` 后面 | 0/3 给动作，只回「我在。不用说话，歇会儿也行」——被 `[最后提醒]` 的「不要急着给办法」压掉 |
| 移到 `[最后提醒]` 之后（现方案） | `listener_todo()` | 1/1 给动作：`那就先不试了。去倒半杯水，慢慢喝完。` |
| 措辞 A（现版） | 「给一个 60 秒能做完的小动作…给完就停，不解释」 | 隔离 3/3 + 管线 1/1 |
| 措辞 B | 「不接话，直接给…」 | 1/3 |
| 措辞 C | B + 「不想动就算了」 | 1/3 |
| 措辞 D | 「对方已经说了三轮，这一轮别再只说陪着…」+ 举例 | 隔离 4/4，**管线 2/2 拒**（模型回「我陪你坐一会儿」） |
| 措辞 F | D + 「前面「不要急着给办法」这一轮不适用」 | 隔离 3/3 + 管线 2/2 合规 |
| 措辞 G | 「你前面几轮一直在陪着。这一轮不能再说陪着」 | 整段 3/3 全拒（负向措辞把模型推回陪伴框架） |

结论：**一句话管不住已经形成的势**。在固定历史里好用的措辞，接在模型自己写出的「我陪你坐会儿」之后就会失效。所以终版用 A 的简版 + few-shot 示例定形状，而不是继续加长措辞。

## 四、示例的两个坑（都实测过）

1. **四轮示例会把第 1 轮改掉**。四轮版跑指纹，echo 反而掉到 2.87：示例首轮「累了一整天，什么都不想动吧」是**解释**而非复述，模型照着示例做，把「接原词」压掉了。示例 > 规则。
2. **四轮 echo 版会抹平人设**。同一个输入「今天有点累，什么都不想干」，5 个人设里 4 个给「累了一整天，什么都不想动吧」。加「按你自己的口吻重写，不要用示例里的词」无效（`now` / `alt` 两版都撞）。
3. 终版**只留后两轮**：前两轮交给规则，第 1 轮口气重新分化（实测 5 人设 5 种开头：听着，是那种提不起劲的累 / 今天就是提不起劲… / 今天累到什么都不想干 / 累到什么都不想干，那就先歇着吧 / 嗯，累了，什么都不想干）。

## 五、改前 / 改后样例（同一输入）

| 输入 | 改前 | 改后 |
|---|---|---|
| 我妈又打电话来了，问我什么时候回家。 | 嗯。你还没想好怎么回 | 她又问什么时候回 |
| 昨天跟室友吵了一架，现在还在想这件事。 | 嗯，吵完还在心里转 | 嗯，吵完了，心还没落下来 |
| 躺了一个小时了，还是睡不着。 | 嗯，躺着也难熬 | 躺了一个小时，还没睡着 |
| 四轮对话末尾（用户答「大概这半个月吧，下班回来就这样」） | `🌿` 等贴纸式安慰 | `半个月了。下班回来，先不急着做什么，去倒半杯水，慢慢喝完`（2/3 次出动作） |

第 4 轮用户只回「嗯」（没接话）时 3/3 不给动作，模型改问「我听着，慢慢说」——判断为合理：对方没接话就不硬塞动作。
