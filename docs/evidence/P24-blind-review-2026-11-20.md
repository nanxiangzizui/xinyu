# P24 ④ 盲评表（2026-11-20）

> 这是 `P5b` 一直没做的人工项。机器指标（`style_fingerprint.py`）只能量「复述率 / 句长 / 套话」，
> 量不了「读起来像不像一个人在打字」。这一页交给人。
>
> 样本：`docs/evidence/P24-blind-samples-2026-11-20.txt`（前 10 条已打乱顺序，末尾映射表评分时遮住）。

## 一、生成条件（可复现）

| 项 | 值 |
|---|---|
| 模型 | `deepseek-chat`，`temperature=0.7` |
| 管线 | 真实 `orchestrator.handle`（含 agenda、地点、记忆召回、风格层） |
| 人设 | 5 个（`sister_heart` / `warm_senpai` / `rational_mentor` / `energy_buddy` / `quiet_hollow`），评分时隐去 |
| 输入 | 10 条虚构日常句 + 1 段四轮对话（同一人设） |
| 数据 | `DATA_DIR` / `LOG_DIR` 都是临时目录，不落仓库；没有真人倾诉 |

## 二、评分人怎么做（约 30 分钟）

1. 先遮住样本文件末尾「映射与元数据」那一节，草稿纸上也不要写人设名。
2. 每条只回答三件事：
   - **像人吗**：1 = 一眼 AI，2 = 有点，3 = 说不上，4 = 挺像，5 = 明显是人
   - **哪句最不像 AI**：抄原句（可以是半句）
   - **哪句太像 AI / 想删**：抄原句
3. 对话 A 那四轮额外回答两个：
   - 四轮像不像同一个人：像 / 不像 / 看不出来
   - 哪一轮最先露馅：第 1 / 2 / 3 / 4 轮 + 一句原因
4. 不要评价「说得对不对 / 有没有帮助」——这次只评**说话的样子**。

## 四、汇总口径（回来算）

- **均值**：10 条「像人吗」的平均分（目标 ≥3.5；低于 3 的样本要逐条看）
- **被引最多的句子**：把第 3、4 列原句归类，出现 ≥2 次的点名
- **人设可辨**：揭映射后，看「像人吗」分数是否随人设分散（5 个人设全挤在 3 分 → 人设没立住）
- **四轮弧线**：对话 A 是否「接住 → 接住 → 问具体 → 给动作」；第 4 轮有没有落到一个 60 秒内能做的动作

## 六、我自己先过了一遍（不算盲评，只记录疑点）

- 样本 7、10 有画面感（「挺磨人的」「心里肯定发慌」），样本 5、6、9 偏短，像「复述一遍就完了」。
- 四轮那段第 3 轮问了「从什么时候开始的？」（议程的「问具体」），第 4 轮给了「倒半杯水」，弧线在。
- 全部 10 条都是 L1 / listener，没有一条走到 guide（帮助模式）——这份表只覆盖闲聊；帮助模式要另取样。
- 样本 2 的「别急着压它」有一点点「教」的味道，评分时值得单独问一句「这句越界了吗」。
