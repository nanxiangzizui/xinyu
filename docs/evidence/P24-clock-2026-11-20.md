# P24 ① 时间感注入（2026-11-20）

## 一、为什么做这一条

来自《AI 活人感案例库（网络实证版）》第 20 条（Gemini 知道用户那边「现在 23:32」）。
在此之前全仓没有任何一处把当前时间拼进 prompt：`datetime` 只出现在 `logger` / `memory` / `panel`
的写盘与文件名里。于是模型只能说「早点睡」「这个点」这类放之四海的话，说重了还会编出一个假钟点。

云上跑的是 UTC（Streamlit Cloud），直接用 `datetime.now()` 会在晚上八点告诉模型「中午」，
所以固定 UTC+8：`agent.CN_TZ = timezone(timedelta(hours=8))`（stdlib，不引 tzdata）。

## 二、改了什么

| 位置 | 改动 | 为什么 |
|---|---|---|
| `agent.py` 顶部 | `from datetime import datetime, timedelta, timezone` + `CN_TZ` | 云上 UTC；固定 +8 才与用户的北京时间对齐 |
| `agent.py:now_line()` | `现在是 2026-11-20 周五 18:44（北京时间）。` | 一句话、带星期与分钟；模型能直接引用 |
| `agent.build_system_prompt` | 事实区之后、`[最后提醒]` 之前追加 `[现在]` 段 | 贴着最后提醒，模型最近一次看到的就是钟点 |
| 同一段追加一句 | 「提到时间以这一行为准，不要自己编钟点；对方没问时不必报具体时间。」 | 实测光给钟点不够：`quiet_hollow` 曾把傍晚说成「快一点了」 |
| `tests/test_clock.py`（新） | 3 条：格式 / UTC+8 对时 / 五个人设都带且排在 `[最后提醒]` 前 | 钟点错了不会报错，只会说错话，必须锁住 |
| `tests/test_roles.py` / `tests/test_knowledge.py` | 软预算 1500→1600 / 1560→1600 | `[现在]` 段约 70 字，最坏实测 1562 |

没有动 `guardian` / `coordinator` / `roles` / `RULES` / `memory` 白名单 / B 模式 prompt /
契约签名；`agent.py` 349 行（≤350）。

## 三、真 key 探针（`docs/evidence/_p24_probe.py` → `_p24_probe_out.txt`）

条件：`deepseek-chat`、temperature=0.7、五人设；对照组把 `[现在]` 段整段删掉。

### A. 直接问「现在几点了？」

| 人设 | 有钟点 | 无钟点 |
|---|---|---|
| sister_heart | 快七点了，周五傍晚。你那边天暗下来了吗？ | 我这边看不到钟呢。你那边现在是白天还是晚上？ |
| warm_senpai | 晚上六点四十四，周五了。今天过得怎么样？ | 我这边看不到时间。你手机上是几点？ |
| rational_mentor | 现在是 18:44。 | 我这边看不到时间。你那边现在几点。 |
| energy_buddy | 六点四十四，周五啦。 | 我这边看不到时间啦，你手机上是几点？ |
| quiet_hollow | 六点四十四。 | 我这边看不到时间。 |

有钟点 5/5 说出正确钟点（脚本按 12 小时与 24 小时两种写法判定）；
无钟点 5/5 承认看不到（前一轮 4/5，属采样波动）。

### B. 语境句「都这个点了，我还没睡，明天早上八点的课。」

- 加「以这一行为准」之前：`quiet_hollow` 回「嗯。快一点了。」——傍晚 18:43 被说成凌晨一点。
- 加「不要自己编钟点；对方没问时不必报具体时间」之后：五人设都落在合理区间
  （「这个点」「快七点了」「周五晚上熬到这个点」），没有再出现与真实时间矛盾的钟点。

结论只能说**方向可用**：n=5 × 2 个条件、temperature=0.7，不是统计意义上的效果量。

## 五、已知限制

1. 只接了 A 模式。B 模式（角色卡）的 prompt 由 `rolecard.build_prompt` 拼，`rolecard.py` 349 行、只剩 1 行，
   本轮没加；角色卡对话目前仍不知道现在几点。
2. 模型仍可能说「快七点」这种近似值；本条的验收是「不编与真实时间矛盾的钟点」，不是逐字报时。
3. 对照组是「删掉 `[现在]` 段」的构造，不是真的回滚到旧版本跑，见 `strip_clock()`。
4. 时间随真实钟点变化，探针结果不能逐字复现，只能复核方法。
