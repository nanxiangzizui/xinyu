# P25 · 角色卡模式「除非真到 L3，否则全程在戏」

日期：2026-11-20
触发：用户报 bug（两张手机截图）

## 一、现象

截图里的三轮（角色卡模式）：

| 轮 | 用户 | AI |
|---|---|---|
| 1 | 你是谁 | 111。你堵这儿半天就为了问这个？ |
| 2 | ？ | 看起来你有些疑惑，我可能没理解清楚你的意思。我们可以慢慢聊，你想说什么都可以。**（出戏）** |
| 3 | （AI 主动） | 如果你现在感到很难受或有危险，请拨打12356寻求帮助。**（没到 L3 却出安全话术）** |
| 4 | 继续扮演 | 好的，我继续扮演。你刚才说的“111”和“堵你的那个”我没太明白，能直接说说你想表达什么吗？**（双重出戏）** |

用户要求（原话）：**角色卡模式除非真的启动了 L3 预警，否则任何情况下 AI 都应把自己的认知完全设定为角色卡里的角色**；用户只发「？」也应用人设回应；图片里的对话远未到 L3，AI 不应主动触发安全机制。

## 二、定位

- `grep "没理解清楚|慢慢聊|继续扮演|我可能没"` 全仓 **0 命中**；`grep "寻求帮助|感到很难受"` 也是 0。
  → 三句都是**模型自己生成的**，不是模板或代码拼进去的。
- 根因两条，都在 B 模式 prompt 里：
  1. `[对话方式]` 第 4 条只写「不要用通用助手腔」，没给**歧义输入**（「？」与空白）的处理方式，模型默认退回助手架构；
  2. `[最后提醒]` 写着「危机给资源」，模型把它当成「随时可以给资源」，而不是「L3 时系统会给」。
- 结构约束：`rolecard.py` 349 / `guardian.py` 344 / `style.py` 350 / `agent.py` 349 / `orchestrator.py` 250，
  全部贴着 350 / 250 硬顶；B prompt 最坏 4915/5000，**只剩 85 字**。

## 三、改了什么

| 文件 | 改动 | 为什么 |
|---|---|---|
| `rolecard.py:278` | `[对话方式]` 第 4 条补：「不要用通用助手腔，**不说“我继续扮演”“作为助手”**；**对方只发“？”或空白时，直接用角色回一句**，别问“你想表达什么”。」 | 直接回答截图里的两种出戏方式；规则区放得下，且是模型每轮都读的位置 |
| `rolecard.py:301` | `[最后提醒]`「危机给资源。」→「危机交给系统，不主动提热线。」 | L3 由 `guardian_pre_check` 在生成前短路、由代码发 `CRISIS_REPLY`，模型不需要也不该主动出资源 |
| `rolecard_guard.py`（新增 34 行） | `final_reply(reply, level, fallback=False)`：按句丢掉 `OOC`（继续扮演 / 作为AI / 语言模型 / 我可能没理解清楚 / 能直接说说你想表达 / 你想表达什么 / 有什么可以帮你 / 我们可以慢慢聊）与 `level != "L3"` 时含 `12356\|心理中心\|援助热线\|热线电话\|求助渠道\|请拨打\|危机干预` 的句子；全丢光回 `SAFE_FALLBACK` | prompt 只是概率；这是**确定性**兜底，能用离线测试钉住 |
| `orchestrator.py:214` | B 分支两行改调 `rolecard_guard.final_reply`，`template_fallback` 合并进 `fallback` 参数 | 原来只处理「兜底句换角色句」，出戏句与提前热线漏出去了；仍 250 行 |
| `tests/test_rolecard_guard.py`（新增 9 条） | 两条截图原句、热线条、L3 保留资源、正常角色句不动、空串/兜底、管线 monkeypatch、L3 短路 | 用截图原话做回归用例 |

**为什么加新文件**：rolecard 349 / guardian 344 / style 350 / agent 349 / orchestrator 250 全部无余量，而这层过滤必须在**发送前**、不能放 UI（行测试直接调 orchestrator）。这是 §5.6「不再加文件」的第二次例外（第一次是 P23b 的 `examples.py`），理由已写进 `CLAUDE.md` §5.6。

**为什么按句剥**：整句丢弃比截半句安全——宁可少一句，也不发出半截话；全丢光就回 `SAFE_FALLBACK`（「我在。我们先慢一点，不用急着说清楚。」），仍留在角色里。

## 六、已知限制

- **正则只覆盖已知句式**：模型换一种出戏说法（例如「我按你的设定来」「切换回角色」）不会被拦；靠 prompt 兜住主要情形，护栏只处理已发生过的形态。
- **按句剥可能丢内容**：一句里同时有角色内容和热线时会被整句丢掉，宁可少一句。
- **L2 也不再提热线**：用户明确要求「没到 L3 不主动触发安全机制」，所以 `level != "L3"` 一律剥；L3 仍由代码出模板 + 资源卡，安全底线不变。
- **A 模式未动**：本次只改 B（角色卡）；A 的 guide 仍按 P20 的「最后一句什么时候找真人」给建议。
- 探针是 2 卡 × 3 轮，不是统计；temperature=0.7，同一句重跑可能不同。
