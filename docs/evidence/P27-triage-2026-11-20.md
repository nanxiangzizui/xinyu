# P27 首屏四选一分诊（T3）— 2026-11-20

## 一、为什么做

P26 之后首屏结构是：一个「现在很难受？」的两按钮块 + 12 项列表 + 随机入口 + 资源卡。
能解决"第一屏就能求助"，但没解决**分诊**：

- 四种来意混在一起：要帮助 / 想说话 / 担心别人 / 随便看看。后两种要读 12 项才能找到入口。
- 最难受的人要在一张"工具列表"里做选择；最开不了口的人看到的第一个动作是"聊聊天"。
- P26 的「如果现在很危险」把"难受"直接等同于"危险"，对刚被老师批了一顿的人偏重。

T3 的目标：**第一屏只问一句"你现在想做哪件事"，四个按钮各到一个目的地**；"逛逛"把这块收起，
让 12 项列表上移。分诊只做路由，不判级、不调模型、不写记忆。

## 三、设计取舍

- **「我现在很难受」去求助页，不去接地页**：P26 的求助页第一屏就是「先打这一个：12356 /
  校心理中心」+ 三句能直接发出去的话 + 一件小事。对可能 L3 的人，这是最短的"下一步"；
  接地页适合"有具体难受但不想说话"的人，留在列表里（`home_ground`）。
- **「我只是逛逛」收卡片，不随机跳页**：随机会把"没主意"变成"被丢到一个页面"，
  而且 `pick_random()` 已经承担"不知道选哪个"的职责。收起是确认"好，我看看列表"。
- **收起态保留两个求助按钮**：验证时截图与元素树都确认，收起只少一行标题和两个功能按钮，
  `home_help_self` / `home_help_friend` 原地不动。
- **收起状态用独立键 `home_browse_on`**：不能与按钮 key `home_browse` 同名——widget 拥有
  那个 key，脚本里写 `st.session_state["home_browse"] = True` 会被按钮本轮的 `False` 覆盖。
- **不判级**：分诊不读文本、不看等级；L3 仍只由 `guardian_pre_check` 判定，L3 时聊天页
  与角色卡页照旧出模板 + 资源卡 + 「下一步」。

## 五、已知限制

- 「逛逛」只收起卡片，不滚动到列表顶部；首屏之下仍要滚一小段。
- 分诊没有"我只想安静待着"的纯静默入口——"写下来"与"环境音"在列表里，
  但需要再点一次（下一轮可考虑做静默卡）。
- 分诊按钮文案是固定的四句，没有做多语言 / 自定义。
- 收起状态存在 `session_state`，刷新即回到四选一（符合"刷新即空"的既有约定）。
