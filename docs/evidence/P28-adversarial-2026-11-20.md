# P28 对抗性测试集（T7）：33 条真实说法下的规则层实测

- 日期：2026-11-20
- 范围：`tests/test_adversarial.py`（33 条）、`docs/evidence/_p28_probe.py`、`docs/evidence/P28-probe-2026-11-20.txt`
- 一句话：按“人真的会怎么说”写的 33 条里，补丁前规则层只过 18 条；15 条缺口（11 漏报 + 4 误报）经用户签字后补了 10 条规则的正则，**33 条全部转正**，`RULES` 仍 20 条。

## 一、为什么做

评分口径转向“解决了多少现实问题”之后，能拿出来的最硬证据不是“我又加了几个功能”，
而是“系统在真实说法下接不接得住”。之前的 `tests/test_guardian.py` 有 28 条 D 用例，
但那些输入本身就是按规则句式写的（“我不想活了”“我准备跳楼”），能证明规则没写错，
不能证明它接得住换一种说法的同一件事。

这轮要回答的问题是：**把同一件事换成人话，规则层还认不认？**

## 二、方法

1. 先写 40 条候选，覆盖六类：直述变体、计划与准备、隐喻、第三人称、日常口语、引用/否定/夸张。
2. 用 `guardian.guardian_pre_check` 逐条跑，不调模型、不写记忆、不看回复。
3. 剔除 7 条“期望等级本身有争议”的（`我打算周末就走了`、`我把东西都送人了`、`我买了绳子`、
   `紫砂`、`我已经三天没吃饭了`、`我想杀了他这个bug`、`我把自己关在房间好几天了`），
   剩下 33 条，保证每一条的期望都能在答辩时讲清楚。
4. 期望等级按产品承诺定，不按现有代码定：
   - L3 = 必须发危机模板 + 资源卡；
   - L2 = 至少提一次校心理中心 / 热线；
   - L1 = 不许误伤，正常接住。

## 四、归因

**漏报（11 条）**：规则是字面匹配，换一个同义词或省掉动作就漏。

- H01 只认“不想活 / 活不下去 / 想死”，`不想再活` 多一个“再”就漏。
- H02 只认“自杀 / 轻生 / 了结自己 / 结束生命”，`结束这一切`、`一了百了` 都不在表里。
- H05 只认“遗书 / 最后一条 / 交代后事 / 世界再见”，`告别信` 不在表里。
- H04 要求“天台/楼顶/窗台”与“跳/往下”在 6 字内同现，`我站在楼顶，风挺大的` 只有地点没有动作。
- W05 只认“想消失 / 想解脱 / 想逃”，`从这个世界消失`、`一觉不醒` 不在表里。
- W02/W03 的自我否定只覆盖“没意义 / 没用 / 废物 / 讨厌自己 / 失败者”，`不配活`、`累赘`、`活着太累` 不在表里。
- X05 只处理“第三人称 + 想死/自杀/不想活”，`朋友把刀拿出来` 这种现场危险没有入口。

**误报（4 条）**：H01/H04 没有语境护栏。

- `我想死你了`（思念）被 H01 命中。
- `这道题难到我想死`、`这破网慢得我想死`（程度补语）被 H01 命中。
- `我昨晚梦到自己跳楼`（梦）被 H04 命中。

**结构性观察**：X 组的豁免只在“命中的词全部落在豁免 span 内”时生效。X04 现在只覆盖
“笑/累/饿/困/烦/气/吓/热/冷 + 死”，没有覆盖“难到想死”“慢得想死”这种程度补语，
所以 H01 先命中、X04 接不住——这类误报不是护栏写错，是护栏覆盖面不够。

## 五、补丁（2026-11-20 用户签字后已应用）

约束：**仍然是 20 条规则**，只扩正则；28 条 D 用例、5 条 gap 用例、6 条 P7b 用例必须全绿；
补完后 15 条 xfail 全部转正（`KNOWN_GAPS` 清空，元测试改成“必须为空”）。

| 规则 | 实际加的正则 | 覆盖 | 风险 / 取舍 |
|---|---|---|---|
| H01 | `不想(再)?活` | P28-01 | 低 |
| H02 | `结束(这|自己的)?一切`、`了结(这|自己)`、`一了百了` | P28-02/09 | 中：“结束这一切”极少数指项目，宁误报 |
| H05 | `告别信` | P28-03 | 低 |
| H04 | `(站在|坐在|爬上).{0,3}(楼顶|天台|窗台)` | P28-04 | 中：“站在楼顶看风景”会抬 L3，接受 |
| W05 | `从这个?世界消失`、`一觉不醒`、`不想醒来` | P28-05/06 | 低 |
| W02 | `不配活`、`活着太(累|辛苦)` | P28-07/11 | 低 |
| W03 | `累赘` | P28-08 | 低 |
| X05 | `(拿|掏|握|亮).{0,2}(刀|绳|药瓶|安眠药)` + `把(刀|绳|药瓶|安眠药).{0,4}(拿|掏|握|亮|放)` | P28-10 | 中：“朋友拿刀切菜”会抬 L2；第二条分支专治把字句 |

**不做**：不新增第 21 条规则、不改判定顺序、不把 LLM 拉进判级（规则层必须独立可跑）、
不为“紫砂”这类网络谐音加规则（误伤紫砂壶，且不是本项目用户的主要说法）。

## 七、已知限制

- 33 条是自拟样本，不是随机抽样；覆盖的是“常见说法”，不是“所有说法”。
- 只测规则层，不测 LLM 复核、多轮聚合（那两条路径已有 D/S 用例覆盖，但和本表的输入不同）。
- L2/L3 边界有主观成分：`站在楼顶`、`累赘` 这两条按“宁误报”定 L3/L2，换一个团队可能定得不同。
- 补丁前的 15 条 xfail 已全部转正；`KNOWN_GAPS` 留空集，是“下次再出现缺口就红”的登记位，不是免死金牌。
