## 3 接口

```text
web.py
  WEB_TIMEOUT_S = 6 / MAX_RESULTS = 5 / QUERY_MAX_CHARS = 80
  TITLE_MAX = 60 / SNIPPET_MAX = 160 / SOURCES_MAX = 3
  ERRORS = ("timeout","http_401","http_429","bad_json",
            "too_large","empty","bad_url")
  search(query, *, fetch=None) -> (data | None, error)
  search_sources(data) -> [{"title","url"}]          # 最多 3 条，P4 渲染用
  is_safe_url(url) -> bool                            # https + 非内网 + 无 userinfo
  register_tools() -> None                            # 注册 ≠ 暴露

transport（可注入）
  fetch(url, headers, timeout_s, body=None) -> (status, bytes)
  抛 TimeoutError 表示超时/连不上；抛 ValueError 表示 URL 非法
```

`_search_remote()` 是唯一知道 provider 的地方；换 provider 只改这一个函数 + `DEFAULT_ENDPOINT`。

## 4 七类错误码与测试

| error | 触发 | 用例 |
|---|---|---|
| `timeout` | `urlopen` 超时 / DNS / 连接失败 | `test_timeout` |
| `http_401` | 401 / 403 / 没配 key | `test_http_401`（+ 冒烟 no-key） |
| `http_429` | 429 限流 | `test_http_429` |
| `bad_json` | 非 JSON / 缺 items / 形状不对 | `test_bad_json` |
| `too_large` | 响应体 > `tools.TOOL_MAX_BYTES` | `test_too_large` |
| `empty` | 合法 JSON 但 0 条结果 | `test_empty` |
| `bad_url` | 非 https / 内网 / userinfo | `test_sources_drop_http_and_private_hosts` |

顺序按文档固定：401/403 → `http_401`，429 → `http_429`，其余 ≥400 → `bad_json`，再判大小，最后解析。

## 7 与步骤文档的偏差（均为防御性小改，测试数不变）

1. **`_normalize` 增加了形状校验**：文档示例直接 `data.get("webPages", {})`，若 provider 返回的 `webPages` 不是 dict、或 `value` 不是 list，会抛 `AttributeError` 冒到 loop。实现改为返回 `(data, err)`，形状不对 → `bad_json`；合法但 0 条仍走 `empty`。9 条用例行为不变。
2. **`_post_json` 兜住 transport 的 `ValueError`**：文档只 catch `TimeoutError`；按 transport 契约 `ValueError` 表示 URL 非法，映射为 `bad_url`，避免非七类错误码外溢。
3. **`_SECRET_KEYS` 必须补三个 WEB_ 键**：P3 文档 §2.2 写“`_bridge_secrets()` 不用改”，但该函数只遍历 `_SECRET_KEYS` 白名单；不补键，Cloud Secrets 里的 `WEB_API_KEY` 永远不会进环境变量。已补（只桥接，不改变本地 `.env` 行为）。
4. **测试用 autouse fixture 清空白名单**：文档的开关用例在末尾手动 `tools.reset()`，断言失败时会污染后续用例；改为 fixture 前后各 reset。sources 用例额外断言带 userinfo 的链接被丢弃。

## 8 安全核对

- query：`memory.scrub` → `strip` → 截断 80 字；只作纯文本，不当 URL。
- 结果：只挑 `title/url/snippet`，title 60 / snippet 160；url 必须 https、非内网、无 userinfo。
- 响应：`read(TOOL_MAX_BYTES + 1)`，超 1 字节即整条失败，不截断后使用。
- 日志：`web provider=... status=... ms=... count=...`，无 query、无结果原文（冒烟已反查）。
- 开关：注册 ≠ 暴露；`ALLOW_WEB=0`（默认）时 `list_for_turn` 过滤网络工具；L3/crisis 返回 `[]`。
- 异常：搜索失败全部变成七类码，不冒到 agent loop；工具层失败留给 `safe_run` 的 L2 兜底。
