# P30 机构衔接三页（2026-11-20）

## 一、为什么做

问题地图里，「机构接不住」是第三个真门槛：P18 之后系统会给出校心理中心的电话和地址，但电话拨通以后呢——

- 第一次去咨询的人，不知道会被问什么，也不知道「说了会不会通知家长」；
- 想请假、缓考、休学的人，不知道该找谁、要什么材料、会不会影响评奖；
- 陪朋友去的人，最容易把自己当成「负责人」，最后两个人都耗在里面。

这三件事都不是「再给一个号码」能解决的，需要的是**去之前能看一眼的流程页**。它们不判断风险、不调模型、不写记忆，只把「怎么问、问什么、怎么陪」写清楚。

## 三、设计取舍

**1. 辅导员页把「说多少」拆成三档，而不是一句「如实说」。**
多数人卡住的不是「要不要说」，而是「说了会不会通知家长」。三档（只说状态 → 说在咨询 → 说具体困难）让人可以**先只走到第一档**，同时把「哪些会被记录、什么情况必须告知」放成四个必问问题。页面不承诺「一定保密」，也不替学校回答。

**2. 请假页只给问题清单，不写政策。**
政策每个学校、每一年都不一样，写死就是过期错误。页面只给三个准备（时间线 / 试过什么 / 想要什么）和五个问题（找谁 / 材料 / 截止 / 影响 / 回来怎么接），并明确「以学校当年文件为准，不替你判断该不该办，也不承诺一定批」。

**3. 陪同页反复写「你不是负责人」。**
照顾者最容易越界：替对方描述症状、替对方答应绝对保密、把这件事当谈资。页面把「能做的」写成三件很小的事（在旁边坐着 / 帮忙记时间 / 回来不追问），把「别做的」写成三条硬边界，最后一段留给陪同者自己（陪完会累；也可以打 12356）。

**4. 危险一律指回 `self` 页。**
三页都不自己处理危机：出现伤害自己 / 找不到人的情况，直接写 110 / 120，并把页面拉回「我现在很难受」那一页（一个号 + 一句能发出去的话 + 一件小事）。流程页不能变成新的「求助终点」。

**5. 不新增文件、不联网、不落盘、不判级。**
全在 `help_pages` 这一层，`mode=help` 的既有路由不变；`guardian` / `roles` / `coordinator` / `memory` / `orchestrator` / `agent` / `style` 一行未改。

## 五、已知限制

1. 政策与流程以学校当年文件为准，页面只能保证「问题问对了」，不能保证答案是最新的。
2. 没有真实的「辅导员—教务—心理中心」办事对照，页面不猜窗口期、不猜材料清单。
3. 不提供预约链接或二维码，避免猜 URL；线上入口仍以首页资源卡为准。
4. 「必须告知家长」的具体边界各学院口径可能不同，页面只写「通常与安全有关，以学校规定为准」。
5. 三页都是静态内容，不记录用户走到了哪一步，也不做跟进提醒。
