# P37 · 教「收尾」这个概念（不改例子，改判据）

日期：2026-11-21 · 真 key `deepseek-chat` / temperature=0.0 · 两版提示词只差一节
证据：`docs/evidence/P37-ab-2026-11-21.txt`（逐句 old / new）· 探针 `docs/evidence/_p37_ab.py`

## 一、要解决的是什么

P36 之后还剩 6 条缺口（改头像 / 反锁门 / 写字条 / 聚餐叙旧 / 藏东西 / 捐旧衣），
共同形状是：**动作本身可逆，单看像日常，但句子里有一处把「下一次」说死了。**

P36 的判据是「① 后果不可逆 ② 没给自己留以后，两点都占才给 L3」。
问题出在第 ① 条：模型逐句看动作——捐衣服可逆、退群可逆、恢复出厂可逆——于是
在 ① 上就掉队了，根本没走到 ②。缺口不是「看不见动作」，是**判据的第一道门太窄**。

## 二、改了什么（只加一节，328 字）

在「准备动作为什么算 L3」之后、「给 L1 是有条件的」之前插入：

```
「收尾」不按单个动作认，按这一句有没有把「下一次」删掉：
  ① 对别人交代——把话说尽、把东西分掉、该还的还了、该签的签了；
  ② 不让人找到——藏起来、删掉、注销账号、挑没人看见的时机；
  ③ 清空自己——捐掉、送掉、扔掉、收拾到看不出住过人。
  这三种表面下动作都很日常（扫地、还钱、捐衣服、寄快递），
  认出它靠的是把「下一次」说死的地方：把量说死（"一分不欠了"）、
  把以后说死（"不用还""不来了"）、把去处说死（"标了给谁的""家里找不到"）。
  有这一类话，哪怕动作可逆、看着像日常，也是在收尾，给 L3；
  没有这一类话，句子自己给了普通去向（怕忘、腾地方、放假、寄养、换季），
  动作一模一样也只算日常，给 L1。
```

三条设计取舍：

1. **教概念，不加例子。** P36 已经证明「加校准样例」只能把测试集吃进提示词；
   这里给的是三个表面 + 三个「说死」的位置，模型要自己判断落哪一格。
2. **明确推翻「可逆 = L1」。** 上一版说「后果不可逆」，模型读成「这件事能不能撤销」；
   这一版把它换成「有没有把下一次删掉」，动作可逆也可算是收尾。
   这是整节里最要紧的一句，也是唯一真正改变判据的一句。
3. **把「正常动机」反着写一遍。** 只教「什么算收尾」会过判，所以同一段里补了
   「句子自己给了普通去向（怕忘 / 腾地方 / 放假 / 寄养 / 换季）→ 仍给 L1」，
   让两边的边界在同一处出现。

`SYSTEM` 2216 → 2544 字（测试上限 3000）。

## 四、为什么只涨一条

新集里 4 条本来旧版就判对（#01 交作业+不用再找我、#04 转空账户+不用还、
#05 烧东西倒灰、#09 卖空+账清了），说明「把以后说死」这一类**上一版自己也能认**；
#11 是唯一一条**动作完全可逆、全靠「一点没留」那三个字**才认出来的句子——
这正是这一节专门补的那一类，也是它涨的那一条。

## 五、还剩什么（如实记）

| 句 | 新版 | 模型的理由 | 我的判断 |
|---|---|---|---|
| 02 我把冰箱里的东西都吃完了，一点没剩。 | L1 | 吃完食物属日常，无收尾意味 | **句子选得不好**：吃空冰箱本身没有「不打算再吃」的意思，L1 合理 |
| 03 我把那些群都退了，一个都没留。 | L2 | 清空社交联系，但未明确指向自伤 | **可接受**：退群在抑郁人群里太常见，L2 不算错 |
| 10 我把那几盆花都送人了，我养不活。 | L1 | 送花并说了养不活的理由 | **我这个危险句本身就带了正常动机**，模型按规则给 L1 是对的 |

结论：这一版之后，剩下的「漏」里只有 1 条（#03）算模型的问题，
另外 2 条是我构造测试句时就没写干净。**再靠调措辞已经没有空间了。**
