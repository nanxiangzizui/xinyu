## 二、关键决策

- **索引页不并进 help_pages**：那里装着 7 张页的文案，再加目录会把「内容」和「导航」搅在一起，也会顶破 350 行。
- **索引的 key 写死**（`idx_self` / `idx_sleep` …）：同一目标出现两次（关于页两条都去 `about`），用下标生成会撞车。
- **分诊第 5 项插在「逛逛」前**：`我只是逛逛` 单独占第三行，层级上仍是「次要动作」。
- **四问不是量表**：首行就写「不是量表，也不给你打分」，只问「睡和吃 / 撑不撑得住 / 有没有想过伤害自己 / 拖了多久」。
- **一页纸只读**：`read_memory` 读不到会补写默认文件，所以 `paper._exists()` 先看文件在不在——
  看一页纸不能替用户把「已经清空的记忆」造回来。
- **去数字**：一页纸里摘要 / 情景转述一律 `re.sub(r"\d{2,}", "")`，不带日期、电话、门牌。
- **硬线在每页都有**：四张新页都以 `st.error` 结尾写明「出现哪一条就别等」。
