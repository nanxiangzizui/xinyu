## 二、四张日常页

四页都在 `help_daily.py`，同一结构：**先接住 → 1 先做 / 今晚 → 2 可照抄 → 3 别做 → 硬线红框 → 资源卡**。不调 agent / orchestrator / guardian，不判级、不写记忆、不联网。

| 页面 | 路由 | 标题 | 核心内容 |
|---|---|---|---|
| 失恋 / 被拒 | `help/love` | 失恋 / 被拒了 | 今晚先不做决定；三句可发的话；别反复看聊天记录 / 别去堵人；出现跟踪、威胁、自伤时升级 |
| 室友 / 宿舍 | `help/roommate` | 室友 / 宿舍住不下去 | 先记录具体发生的事；怎么开口；别在群里对骂 / 别自己搬走；找宿管、辅导员，问换宿流程 |
| 和家里 | `help/family` | 和家里吵完 / 要不要告诉家里 | 先让情绪落地；三句可发的话；**要不要告诉家里**拆三档；别用「断绝关系」当唯一办法 |
| 钱 | `help/money` | 生活费不够 / 兼职被坑 / 校园贷 | 先算清这个月缺口；三句可发的话；别借新贷还旧贷 / 别交押金；校园贷、威胁催收的硬线 |

`family()` 里的「要不要告诉家里」三档：只说近况 / 说在咨询 / 说具体困难；每档都写明「父母可能不理解，不代表你不能说」，并给一句可以直接发的开头。

## 三、四个 section

都加在已有的 `help_scenes.py` 页面里，不新增路由。

1. **朋友页「他不肯去，我怎么劝」**（`FRIEND_REFUSE`）
   - 先问「你怕的是什么」；三句可照抄：「我陪你去，到了你不用说什么」「不想去也行，今晚先坐一会儿」「我不逼你，但你有危险我会找人」。
   - 别做：别威胁不管他、别替他预约、别答应「有危险也保密」。
   - 硬线：明确的自伤 / 伤人计划 → 110 / 120 / 辅导员。

2. **朋友页「网上看到有人想不开，我是旁观者」**（`FRIEND_ONLINE`）
   - 先私信「我在，你还好吗」；别在评论区问细节、别刺激、别把截图发群里。
   - 如果对方给出明确时间、地点、方式，或正在直播、已经吃药 → 110 / 120 + 平台客服。
   - 不围观、不转发、不截图传播。

3. **网暴页「如果你是旁观者」**（`ONLINE_WITNESS`，第 5 节；原「这几天怎么过」顺延为第 6 节）
   - 不转发、不保存隐私图、不围观；私信当事人；帮存证时带时间和链接。
   - 危险时 110 / 120；平台举报 + 辅导员；别对骂、别肉搜、别二次曝光。

4. **考砸页「挂科 / 退学警告」**（`EXAM_FAIL`，第 5 节）
   - 先分「一门」还是「多门 / 学业警告 / 退学警告」；问清补考时间、重修算法、对毕业和学位的影响。
   - 可照抄：「老师，我收到了学业预警 / 退学警告，想问问现在有哪些选择，最晚什么时候办。」
   - 别拖过截止、别信「花钱消记录」、别一个人猜政策；撑不住时 12356 / 校心理中心。

## 四、60 秒出口

`help_daily.SIXTY` 覆盖 15 个内容页：

```text
self / friend / before / after / teacher / leave / accompany /
aftermath / sleep / online / exam / love / roommate / family / money
```

每页末尾统一三句：

1. 这一页只做一件：……
2. 做不到就做更小的：……
3. 出现什么就升级：……

下面一个按钮「去和心屿说这件事」，key 为 `help_chat_<page>`，点击写 `mode="companion"` 并 `st.rerun()`。

挂载点在 `help_pages.render()` 末尾，**只挂一次**；`help/index` 与 `help/paper` 早返回，不挂。第一次跑测试时 19 条失败，原因是四个页面函数里也调了 `sixty_seconds()`，同屏出现两个 `help_chat_roommate`，报 `StreamlitDuplicateElementKey`；删掉页面函数里的调用后恢复。

- 搜索框 `st.text_input("搜一个词", key="idx_search", placeholder="室友、失眠、钱、分手、家里、挂科……")`。
- `KEYWORDS` 按 idx key 维护；`_matches(query)` 按空格分词，要求每个词都命中。
- 空结果：`st.info("没找到。可能这一页还没做——你可以去聊天里说说这件事。")` + 按钮 `idx_no_match_chat`，直接进陪伴模式。
