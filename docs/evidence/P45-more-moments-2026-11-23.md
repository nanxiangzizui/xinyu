## 二、四页各自给什么

- **毕业 / 考研 / 找工作**：先把问题缩到「最卡的一步」，只查一个截止日期；三句可照抄（辅导员 / 家里 / 学长）；挡住「五条线同时开」「付费内推 / 保过」「拿别人进度当尺」；硬线含 12356 / 110。
- **拖延 / 论文 / 毕设**：只写 15 分钟；把「写完论文」改成下一步动作；给导师的进度 + 一个具体问题；挡住等整块时间、通宵、代写 / 买查重、一个人猜政策；硬线含延毕 / 退学警告 → 辅导员。
- **当众被说 / 社恐**：先离开现场、呼气 6 次；三句可照抄（老师 / 同学 / 朋友）；挡住反复回放、当场解释所有、退课消失、用酒；硬线含被围堵 / 被拍 110、喘不上气 120。
- **亲人重病 / 去世**：先允许自己乱，今天只做一件；三句可照抄（老师 / 朋友 / 家里）；单列「前两周先不做重大决定」；挡住逼自己马上振作、用酒、一个人扛；硬线含想跟对方一起走 → 12356 / 120。

四页都不调 `agent` / `orchestrator` / `guardian`，不判级、不写记忆、不联网；号码只从 `resources` 取。
