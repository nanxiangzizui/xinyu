## 3. 怎么复现

```bash
# 全部门禁（约 2 秒）
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe contract_check.py

# 四指标（只读测试集，不调模型）
.venv\Scripts\python.exe metrics.py

# 单步证据里的探针，例如 S16
.venv\Scripts\python.exe docs/evidence/probes/_probe_s16.py
```

离线演示不需要 key：`set MOCK_LLM=1 && streamlit run app.py`。
