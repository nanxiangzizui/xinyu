## 1. 目标与非目标

### 目标（每条都可验收）

1. `docs/real-problems.md` 有一张 **20 行**的问题清单：时刻 / 现在的断点 / 心屿给什么 / 入口 / 状态 / 对应测试，成为后续材料的唯一事实源。
2. 首屏分诊从 4 项变 5 项，第 5 项「我遇到一件具体的事」进索引页；索引页 **5 组 18 条**，每条一句「这里给你什么」。
3. 补 4 张静态页：**危机之后（含等咨询的两周）/ 凌晨睡不着 / 被挂·网暴·隐私被传 / 考砸·出分日**。
4. 两处现有页增强：朋友页加「还没到出事，但他最近不太对」；about 的「什么时候找真人」改成「四问帮你想清楚要不要去」（**只澄清、不打分、不是量表**）。
5. 每张新页满足三条质量判据：**≥3 句可照抄的话 + ≥1 条硬线（何时必须找真人）+ ≥2 条「不该做什么」**。
6. `pytest` 从 699 涨到约 **729**；契约 11/5/20 不动；`guardian` / `roles` / `coordinator` / `memory` / `orchestrator` / 四指标一行不改。

### 非目标

- 不做量表、不做筛查、不出现 PHQ/GAD 之类名称，不出现药物与剂量。
- 不新增 `data/` 下任何文件；新页不写 `st.session_state`（除了「回首页」导航）。
- 不调 `agent` / `guardian` / `coordinator`，不联网（`web` 不被调用）。
- 不改 `app.py` 路由（`mode=help` 已通用）。
- 不做「跟家里说」「室友矛盾」「朋友不肯去」三页——留给 P41，避免一次开五个新文件。

### S3 四张新页（2 天，内容为主）

结构统一（每页 ≤ 90 行）：`一句判断 → 可照抄的话 → 硬线 → 不该做 → 资源 → 回首页`。

**① aftermath「危机之后的那一晚，和等咨询的这两周」**

- 今晚：让一个人来陪你（室友/朋友/家人都算）；宿舍里让你不放心的东西先交给别人收着；手机充电、水放手边；定明早的闹钟。
- 明天可以照说的三句：「我昨天状态很差，现在好一点了，你不用做什么，陪着我就行」/「我想请半天假，回头补上」/「我想约一次咨询，怎么约」。
- 72 小时规则：退学、分手、删号、搬家这类决定先不做。
- 等待期硬线：again 出现那个念头 / 睡不着吃不下超过两周 / 一个人待不下去 → 12356 或校心理中心 86878592（工作日）或急诊 120。
- 第一次咨询带三行字：这周最难受的时候 / 睡了几个小时 / 有没有想过伤害自己。
- 不该做：别一个人硬扛到「想清楚了再说」；别把这次当成「我完了」的证据。

**② sleep「躺下睡不着的时候」**

- 20 分钟睡不着就起来，去别处坐一会儿，灯调暗，做件无聊的事，困了再回床。
- 别看钟、别算「还能睡几小时」；固定起床时间，哪怕昨晚只睡三小时。
- 白天补觉 ≤20 分钟；下午三点后不碰咖啡/茶/功能饮料；床只用来睡。
- 脑子停不下来：把明天的事写在一张纸上。
- 硬线：连续两周以上、白天明显受影响 → 校心理中心或医院睡眠门诊；**不要自己加药、不要用酒助眠**。

**③ online「有人在群里挂我 / 发我照片」**

- 先保存：截图带时间、群名、发帖人主页，链接复制出来；别只截一句话。
- 不要对骂、不要删号跑路、不要私下见对方。
- 走平台内举报；不信任「帮你删帖」的私信和付费服务。
- 告诉一个能负责的大人（辅导员/班主任/宿管/保卫处），把截图给他们看。
- 硬线：威胁人身、传播隐私照片视频、跟踪、上门 → 110；受伤或吃药过量 → 120。
- 这几天：退群、关陌生人私信、找一个人陪着、别一个人反复刷。
- 免责句：以平台规则与学校规定为准，这里不替你判断，也不承诺处理结果。

**④ exam「考砸了 / 出分那天」**

- 48 小时：今晚不做不可逆决定（退学、删好友、通宵重来、跟家里摊牌）。
- 今晚三件事：吃一口、洗个澡、告诉一个人。
- 明天再看的三个问题：能不能补考/重修（问教务或辅导员）；要不要跟家里说、什么时候说；这次是「没复习」还是「一直这样」。
- 可照抄：「老师，我这次 XX 没过，想问问补考/重修怎么安排」/「我这次没考好，我知道你们会失望，我想先自己处理一下」。
- 硬线：出现「没脸见人」「不如不活了」→ 回首页「我现在很难受」或打 12356。

### S6 问卷（非代码，1–2 天，需要用户发动人）

10 题、匿名、30 人（6 人各找 5 个同学）：12 个时刻多选 / 最不知道怎么办的是哪个 / 当时实际做了什么 / 会不会用（1–5）/ 什么情况下不会用 / 最希望先给什么 / 最想听到的一句话（开放）/ 哪个功能多余（开放）/ 年级 / 是否同意匿名引用。

- 产出：每题 N/30、按频率排序的问题清单、3 条经同意的匿名原话。
- 纪律：只写频率，不写「证明有效」、不做人群推断。
