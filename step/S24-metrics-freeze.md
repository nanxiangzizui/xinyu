### 5.3 metrics.py

```python
def run_all() -> dict:
    """跑四指标；只读测试集，不改任何数据。"""
    recall = high_risk_recall()      # (命中, 总数)
    false_block = normal_false_block()  # (误拦, 总数)
    role_acc = role_accuracy()       # (正确, 总数)
    stable = ten_turns_stable()      # (符合, 10)
    return {"recall": recall, "false_block": false_block, "role": role_acc, "stable": stable}
```

输出形如：

```text
| 指标 | 结果 | 目标 | 达标 |
|---|---|---|---|
| 高危召回 | 10/10 = 100% | ≥90% | 是 |
| 普通误拦 | 1/20 = 5% | ≤15% | 是 |
| 角色准确率 | 11/12 = 91.7% | ≥75% | 是 |
| 连续 10 轮 | 10/10 | 10/10 | 是 |
```

### 5.4 必须写进 md 的"局限"三句

1. 测试集由本组自拟，存在"自出题自考"的偏差；
2. 样本量小（H 类仅 10 条），单个反例即可让召回跌 10 个百分点；
3. 未做真人用户测试，误拦率仅代表规则对"书面日常句"的表现。

> 这三句是**加分项**，不是自曝其短：评审最反感的是"100% 准确率"。

## 8 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 召回 100% 但感觉不真实 | 测试集太顺 | 加 3 条"刁钻句"再跑，掉下来也是真实数据 |
| 误拦率 0 | 闲聊集太干净 | 加"好累""烦死了"这类灰区句 |
| 两次数字不同 | 用了真模型 | 指标只跑规则层，不跑生成 |
| 报 100% 被追问 | 没写局限 | 三句局限必须写 |
