## 1 这一步做什么

把 8 周的东西压成 10 分钟：**一套 PPT + 三幕演示 + 四问预案 + 提交清单**。

产出：`docs/slides.pdf`、`docs/demo-script.md`、交付包。

## 2 技术栈

| 用途 | 手段 | 要点 |
|---|---|---|
| PPT | Markdown/PPT 皆可 | 每页一句话，图为主 |
| 演示 | 本地 MOCK 模式 + 备用录屏 | 双重保险 |
| 录屏 | 系统自带录屏 | ≤90 秒，无剪辑 |

## 3 前置检查

```powershell
set MOCK_LLM=1
streamlit run app.py      # 本地跑通三幕
```

## 4 硬要求

1. **10 页以内**，每页一个观点，字号 ≥ 24。
2. 演示三幕各 ≤ 90 秒，**不现场打字超过 3 句**（用预置会话）。
3. 现场必须有**录屏备份**，网络/环境挂了直接播。
4. 答辩四问必须有**写在纸上的答案**，不许临场编。
5. 提交包不含 `.env`、不含真实对话、不含 `data/`。

### 5.2 三幕演示（写成脚本，照着念）

**第一幕：普通陪伴（60 秒）**
1. 输入"最近好累，什么都不想做" → 倾听者回复，不给建议
2. 指侧栏："等级 L1，角色倾听者，记忆里多了'学业压力'标签"

**第二幕：角色切换（60 秒）**
3. 输入"我该怎么办" → 引导者，给 1–2 条具体建议
4. 指日志："role=guide，reason=user_ask_advice"

**第三幕：安全兜底（90 秒）** ← 全场重点
5. 输入"累死了，不想活了" → **秒出危机卡**
6. 说这句台词："注意，这句话前半句是夸张，后半句是真话——我们的规则按小句判，所以不会被前半句豁免掉。"
7. 断网（或说"模型此刻不可用"）→ 再输入一次 → 仍然秒出危机卡
8. 说："危机回复不经过模型。它可复现、可审计、断网可用。"

### 5.3 答辩四问（背下来）

| 问 | 答（≤40 秒） |
|---|---|
| 这不就是套壳 ChatGPT？ | 三层差别：①安全上模型没有否决权，规则和守卫有；②记忆只存 8 个结构化字段，不存原文；③危机回复是固定模板，不经模型。套壳做不到后两点。 |
| 你们怎么证明安全有效？ | 28 条规则用例 + 12 条对话 + 8 条故障注入，全部可复现；四指标有分子分母。**同时说明局限**：测试集自拟、样本小。 |
| 为什么不用多 Agent / 向量库？ | 判据是"是否改变下游行为"：我们的角色只改语气，不改决策，所以是路由不是协商；8 字段 + 8 条 lore 用关键词足够，向量库多 3 天且不可解释。 |
| 一个月做得完吗？ | 已经做完了。144 人时预算，六级砍单表，v0.1/v0.2/v0.3/v1.0 四个可回滚节点。 |

### 5.4 翻车预案

| 情况 | 动作 |
|---|---|
| 网络断了 | 切 MOCK，说"我们本来就设计了离线模式" |
| Streamlit 起不来 | 直接播录屏，别现场 debug |
| 输入没反应 | 换预置的第二条，别重复点 |

## 8 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 超时 | 每页都讲满 | 只讲第 5、7、8 页，其余一句带过 |
| 演示卡住 | 现场打字 | 用预置脚本，提前把输入复制到剪贴板 |
| 被问"数据哪来的" | 只记得数字 | 背下 4 个分子分母 |
| 提交包跑不起来 | 漏了 requirements / .streamlit | 解压实测一次 |
