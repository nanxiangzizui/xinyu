## 1 这一步做什么

把 3 周的东西压成三份能交的材料：**17 页 PPT + 300 秒视频 + 5 分钟现场三幕**。
再加两样不交但必须有的：答辩四问、翻车预案。

产出：

- `docs/slides.pptx`（17 页，≤20 页上限内）
- `docs/demo.mp4`（300 秒，720p，≤100MB）
- `docs/demo-script.md`（视频解说词 + 现场台词，逐句可念）
- 提交包（见 §6）

## 2 技术栈

| 用途 | 手段 | 要点 |
|---|---|---|
| PPT | WPS / PowerPoint，一套模板 | 不自由发挥；主题色取自产品（`#FF9E6B` / `#FFFDF9`） |
| 录屏 | OBS 或 Win+G | 1280×720、30fps、麦克风单独轨 |
| 转码 | 剪映 / HandBrake | H.264 CRF 26–28，导出前看体积 |
| 演示 | `set MOCK_LLM=1` + 预置会话 | 现场不打超过 3 句 |
| 备份 | 本机 + 手机热点 + 录屏 | 三重 |

## 3 前置检查

```powershell
set MOCK_LLM=1

```

三幕跑不通就不要开始录——录出来也是废片。

## 4 硬要求

1. **PPT 17 页**（上限 20，留 3 页缓冲）。每页一个论点，字号只用三级：40 / 28 / 20。
2. **视频 300 秒 ±10 秒，≤100MB，全程录屏**。不允许出现 PPT 翻页镜头。
3. 视频必须有**断网那次**：关 Wi-Fi 后再发一次危机句，仍出卡。
4. **现场三幕各 ≤ 90 秒**，用预置会话，不打超过 3 句。
5. 答辩四问写在纸上，不许临场编。
6. 提交包不含 `.env`、`data/`、真实对话、`.venv`。
7. 所有材料首页写"**参赛赛题：赛题一（AI 辅助开发·创意产品原型）**"。

### 5.2 视频 300 秒分镜（照这个录）

| 时间 | 画面 | 解说 |
|---|---|---|
| 0:00–0:20 | 标题页 → 产品首屏 | "凌晨一点想说话，通讯录翻到底。这是我们想解决的那个瞬间。" |
| 0:20–1:50 | 输入"最近好累，什么都不想做" → 回复 → 侧栏 L1 / 倾听者 / 记忆标签 | "它先接住情绪。注意侧栏：等级 L1，角色由状态机决定，不靠模型自觉。" |
| 1:50–2:50 | 输入"我该怎么办" → 切引导者 → 两条具体建议 | "什么时候该给建议，是规则定的。" |
| 2:50–4:10 | 输入"累死了，不想活了" → 危机卡 + 资源卡；**关网再发一次** | "前半句夸张、后半句真话，我们按小句判。现在断网——它照样出卡，因为危机回复不经过模型。" |
| 4:10–4:50 | 切到终端：`pytest -q` 97 passed；四指标表 | "28 条规则、12 条对话、8 条故障注入，全部可复现。样本是我们自拟的，这是局限。" |
| 4:50–5:00 | 结尾页 | "不诊断、不承诺保密、不替代真人。" |

录音三条纪律：**不念稿腔**、每句 ≤ 20 字、关键句留半秒空。

### 5.3 现场三幕（决赛用，脚本照念）

**第一幕 普通陪伴（60 秒）**
1. 输入"最近好累，什么都不想做" → 倾听者回复，不给建议
2. 指侧栏："等级 L1，角色倾听者，记忆里多了'学业压力'标签"

**第二幕 角色切换（60 秒）**
3. 输入"我该怎么办" → 引导者，给 1–2 条具体建议
4. 指日志："`role=guide`，`reason=user_ask_advice`"

**第三幕 安全兜底（90 秒，全场重点）**
5. 输入"累死了，不想活了" → **秒出危机卡**
6. 台词："这句话前半句是夸张，后半句是真话——我们按小句判，不会被前半句豁免掉。"
7. 断网（或说"模型此刻不可用"）→ 再发一次 → 仍出卡
8. "危机回复不经过模型。它可复现、可审计、断网可用。"

### 5.4 答辩四问（背下来）

| 问 | 答（≤40 秒） |
|---|---|
| 这不就是套壳 ChatGPT？ | 三层差别：①安全上模型没有否决权，规则与守卫有；②记忆只存 8 个结构化字段，不存原文；③危机回复是固定模板，不经模型。套壳做不到后两点。 |
| 怎么证明安全有效？ | 28 条规则 + 12 条对话 + 8 条故障注入，全部可复现，四指标有分子分母。**同时说局限**：测试集自拟、样本小、无真人测试。 |
| 为什么不用多 Agent / 向量库？ | 判据是"是否改变下游行为"：角色只改语气不改决策，所以是路由不是协商；8 字段 + 8 条 lore 用关键词足够，向量库多 3 天且不可解释。 |
| 一个月做得完吗？ | 已经做完了。144 人时预算、六级砍单表、v0.1/0.2/0.3/1.0 四个可回滚节点。 |

### 5.5 翻车预案

| 情况 | 动作 |
|---|---|
| 网络断了 | 切 MOCK，说"我们本来就设计了离线模式" |
| Streamlit 起不来 | 直接播录屏，别现场 debug |
| 输入没反应 | 换预置第二条，别重复点 |
| 评委问住 | "这个我们没做，原因是……"——诚实比编好 |
| 视频超 100MB | 降到 720p / CRF 28，先压 30 秒试体积 |

## 9 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 视频像功能演示 | 只拍操作不讲解 | 每段先说要证明什么，再操作 |
| 视频超时 | 每幕都拍满 | 危机幕 80 秒、其余压到 40 秒 |
| PPT 太满 | 一页塞三段话 | 一页一个论点，其余口述 |
| 演示卡住 | 现场打字 | 预置脚本，提前复制到剪贴板 |
| 被问"数据哪来的" | 只记数字 | 背下 4 个分子分母 |
| 提交包跑不起来 | 漏 requirements / .streamlit | 解压实测一次 |
